Meme雷达开源版 · Windows x64

一键版使用方法：
1. 必须先把整个压缩包“全部解压”，不能直接在压缩软件里运行。
2. 进入解压后的文件夹，双击 MemeRadar-OpenSource.exe；便携包已经包含运行环境，不用安装 Node.js。
3. 浏览器打开后，点击“首次使用 / 创建 API”。
4. 复制雷达生成的 Agent 公钥，在 GMGN 创建新的 API Key：只开启读取，关闭交易。
5. 把新 API Key 填回雷达并点击“✓”，验证成功后开始扫描。
6. 每次创建新的 API Key 都必须重新完成 Agent 公钥绑定。

如果浏览器没有自动打开，请手动访问：
http://127.0.0.1:3791/

运行期间请保留黑色窗口，关闭窗口会停止本地雷达。
网络提示：便携版会自动读取 Windows 系统代理。若连接 GMGN 超时，请先确认浏览器能打开 GMGN，并在代理/VPN软件中开启“系统代理”，然后完全关闭雷达黑色窗口再重新启动。
